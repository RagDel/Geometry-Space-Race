# Credits and publication scope

Geometry Space Race is directed by Tilemachos Tragakis. Codex assists with implementation, debugging, tests, documentation, and asset preparation. The project combines procedural work, generated visuals, owner-supplied resources, and third-party assets; the portfolio does not claim sole manual authorship of every component.

## Assets seen or used in the private game

The screenshots show the game's integrated presentation, including supplied spacecraft, generated UI/environment artwork, and the Zen Dots font. Model source metadata identifies Tripo; sky and tunnel source filenames identify generated imagery. Font provenance is recorded in the private project's bundled notices.

The private game uses Kenney CC0 sound assets alongside separately supplied Epidemic Sound effects and a supplied soundtrack credited to **magneticcrowdsurfing458**, whose source metadata identifies Suno. Other supplied audio has its own integration record. These sources are credited separately because their permissions differ.

## What is published

- Four unchanged in-engine screenshots, with capture origins and hashes.
- Newly written gameplay, architecture, and verification documentation.
- Five unchanged production C# source files, with extraction provenance.
- A small standalone verification harness for the portable sample.

No raw model, texture, font, sound, or music files are distributed here. The complete Unity project, development binaries, private planning vault, local settings, raw diagnostics, and original Git history remain outside this repository. Existing game-use confirmations for supplied media are not treated as permission for standalone source-asset redistribution.

This repository is a portfolio showcase. No additional reuse license is granted for its code or images, and third-party rights remain with their respective owners. Public visibility does not convert the private game's supplied assets into CC0 or grant rights to extract them from screenshots.
